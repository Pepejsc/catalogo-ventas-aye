CATALOGO - GITHUB PAGES
======================

Este proyecto ya tiene 10 contenedores de productos.

Para poner una imagen:
1. Guarda la foto dentro de la carpeta assets.
2. En products.js cambia image:"" por, por ejemplo:
   image:"assets/producto-01.jpg"

También puedes cambiar nombre, categoría, descripción, precio, cantidad/stock y colores.

Para publicar:
1. Crea un repositorio público en GitHub.
2. Sube TODO el contenido de esta carpeta.
3. Ve a Settings > Pages.
4. Source: Deploy from a branch.
5. Branch: main / root.
6. Guarda y espera la publicación.
